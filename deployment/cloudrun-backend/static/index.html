Why LightGBM was promoted

Five models were trained on 67 engineered features (15,259 training rows), spanning a linear baseline to optimized gradient boosting, so gains could be attributed to model capability. All were tracked in MLflow. LightGBM achieved the lowest validation RMSE and was registered as the champion in the model registry. Because the serving API loads the model by its champion alias, promoting a retrained model to production is a single registry update — no change to the serving code or this dashboard.
Governance data from the MLflow model registry and experiment tracking. The three near-tied boosting methods confirm the result is robust; the ~3-cycle RMSE gap over Linear Regression confirms the degradation pattern is non-linear.
